Parameters: giving a function information

  
So far our functions have done exactly the same thing every time. Parameters let you give a function some information to work with. A parameter is a placeholder written inside the parentheses, and each time you call the function it gets filled in with the value you pass.

  


def greet(name):
    print("Hi " + name)

greet("Maya")

More than one parameter

  
A function can have as many parameters as you need, separated by commas. When you call it, the arguments fill the parameters in order, so the first argument goes into the first parameter, the second goes into the second, and so on.

Using what a function returns

  
When a function returns a value, you can use the call anywhere you could use the value itself. Python runs the function and then swaps the call for whatever it returned.

  







  
Return ends the function

  
As soon as Python reaches a return, it leaves the function, so any lines that come after it inside the function never run.

  







  
No return means None

  
If a function doesn't return anything, calling it gives back a special value called None, which is Python's way of saying "nothing". In the code below, say_hello prints a greeting but doesn't return anything, so look at what ends up in x.

Variables inside stay inside

  
Every time a function is called, it gets its own box in memory. Any variables you create inside the function live in that box, and when the function finishes, the box is cleared away along with everything in it.

  

  
If you need a value from inside a function, the way to get it out is to return it.







  
Functions can call other functions

  
When one function calls another, the new call gets its own box on top of the others. When that function finishes, its box is cleared and Python picks up where it left off in the box underneath.
