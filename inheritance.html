Last week's Dog class

Last week we wrote a Dog class. Every dog has a name and an age, and it can have a birthday and bark. Run it to remind yourself how it works.

Now we want cats too

A cat also has a name and an age, and it can have a birthday. The only difference is that it meows instead of barking.

Most of Cat is copied from Dog. If we want to change how birthdays work, we have to remember to change it in both classes, and it gets worse with every new animal we add.

Inheritance

Instead of copying, we can put the shared code in one class called Pet. Then we tell Python that a Dog is a Pet and a Cat is a Pet, and they both get everything Pet has. This is called inheritance.

  • Pet is the parent class
  • Dog and Cat are child classes
  • A child class inherits every attribute and method from its parent
  • A child class can also add things of its own, like bark

Writing a child class

To make a child class, put the parent's name in parentheses after the class name

How Python finds a method

When you call a method, Python looks in the object's own class first. If the method isn't there, it looks in the parent class. Pick an object and call a method to see where Python finds it.

When to use inheritance

  
Use inheritance when one thing is a kind of the other. If one thing only has the other, use an attribute instead. Pick the sentence that sounds right for each pair.
