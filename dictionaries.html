Dictionary

A dictionary stores data in pairs. Each name is kept right next to its score so there's no index to search for. You ask for Sam and you get 72.

Getting a value

To get a value put its key in square brackets. It looks like list indexing but instead of scores[1] you write scores["Sam"].

Adding, changing and removing

To add a pair assign a value to a new key. Each key can only be in a dictionary once. If the key is already there its value gets replaced. del removes a pair.

Checking for a key

Asking for a key that isn't there stops the program. Use in to check first. It's True when the key is in the dictionary and False when it isn't.
