Reading a file

  
A file has a name, like groceries.txt, and it holds text. You can see what's in this file on the right. A program has to open a file before it can read it. Step through the code to see what each line does.

  







  
Reading line by line

  
Most of the time we want to go through a file one line at a time. A for loop over a file gives us the next line each time around, the same way a loop over a list gives us the next item. Watch the output as you step through.

  







  
Removing the \n

  
We almost never want the \n that comes at the end of each line. Strings have a method called strip() that gives back the same string with the \n taken off the end. It also takes off any spaces at the start or the end. So "milk\n".strip() is "milk".

  

  
Run the program to see the empty lines again, then press Fix it. strip() doesn't change line itself. It gives back a new string, so we write line = line.strip() to put the new string back in line. You'll do this almost every time you read lines from a file.







  
Numbers in a file

  
scores.txt has a quiz score on each line, and we want to add them up. Everything we read from a file is a string, even when it looks like a number. The same thing happened with input(), and the fix is the same. We turn the string into a number with int().

  







  
Writing a file

  
A program can also put text into a file. To do that, we give open a second value, "w", which stands for write. Then we use f.write() to add text to the file.

  







  
"w" starts over and "a" adds on

  
Opening a file with "w" empties the file first, even if it already had text in it. Run this program three times and look at log.txt after each run. Then change "w" to "a", which stands for append, and run it three more times.

Now we can fix the counter from the second slide. The count is kept in a file called count.txt, which has a 0 in it to start. The program reads the number from the file, adds 1 to it, and writes the new number back to the file. Run it a few times.

CSV files

  

    

      
A lot of information comes as a table, with rows and columns. A CSV file is a table saved as text. Each line of the file is one row of the table, and commas separate the columns. CSV stands for comma-separated values.

      
The first line is different from the rest. It has the names of the columns. Press Table above the file to see it as a table, and Text to go back.

    

    

      

      
This file is from a 2017 survey by the news site FiveThirtyEight. People were shown two candies at a time and picked the one they liked more. win_percent is the percent of the time each candy was picked. The other two columns say whether the candy has chocolate and whether it is fruity.

Modules

  
Python comes with a lot of code that is already written, like a function that finds a square root and a function that picks a random number. This code is kept in files called modules. To use a module, we import it by name at the top of our program.

  







  
The csv module

  
Python has a module for reading CSV files, called csv. The part of it we'll use is csv.DictReader. We give it an open file and loop over it, and each time around the loop it gives us the next row of the table as a dictionary.

  







  
Asking the file a question

  
Now we can ask questions about the candies. Which ones win more than 75 percent of the time? The loop goes through every row, and the if only prints the rows where the win percent is over 75. The win percent is a string when it comes out of the file, so we turn it into a number with int() before we compare it.

  

  
Change 75 to another number and run it again. Then try changing the if so that it prints only the fruity candies. The fruity column is "yes" for those.







  
The statistics module

  
What is the average win percent? First we put every win percent in a list called wins. Then we use a module called statistics. It has a function called mean that takes a list of numbers and returns their average.

  

  
"Mean" is another word for average. statistics.median returns the middle number, which is the number that would be in the middle if the list were sorted from smallest to biggest.







  
Chocolate or fruity?

  
Do people like chocolate more than fruity candy? To find out, we make two lists. If a candy has "yes" in the chocolate column, its win percent goes in the chocolate list. If it has "yes" in the fruity column, its win percent goes in the fruity list. Make a guess, then run the code.

  

  
Chocolate candies win about 61 percent of the time, and fruity candies win 44 percent of the time. People picked chocolate a lot more often.







  
Making your own module

  
A module is a file of Python code, so we can make our own. This program has two files. candy_tools.py is our module, and it has two functions in it. main.py imports the module and uses those functions.

  

  
Click the candy_tools.py tab to read the two functions. load reads a CSV file and returns a list that has a dictionary for every row. average adds up one column of those rows and divides by the number of rows. In main.py, the name we import is the file's name without the .py, and after that it works the way math did. Any other program in the same folder can import candy_tools too.







  
What import does

  
What does Python do when it gets to an import line? It goes to that file and runs it from top to bottom. Then it comes back and continues with the next line. The yellow line shows which line is running, so watch it move between the two files.

  







  
Tests in a module

  
We want the test to run when we run tools.py ourselves, and to stay out of the way when another file imports it. Python gives every file a variable called __name__, with two underscores on each side. In the file that we ran, it is set to "__main__". In a file that was imported, it is set to the module's name, like "tools". So the if at the bottom of tools.py is only true when tools.py is the file we ran.

  

  
Run main.py, and only one line prints. Then click the tools.py tab and press Run again. Now tools.py is the file being run, so its test prints. The Run button always runs the tab that is open, here and in the compiler.







  
A class in a module

  
A module can have a class in it too. candy.py has a Candy class, and a function called load_candies that reads the file and makes a Candy object for every row. Read both tabs, then run main.py.

  

  
The first line of main.py is a second way to import. The module's name goes after from, and the names we want out of it go after import. Now we can write Candy(...) without putting candy. in front of it.
